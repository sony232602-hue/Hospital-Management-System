# 🏥 Hospital Management System

## 📌 Description

The Hospital Management System is a Java-based application designed to manage patients, doctors, and appointments efficiently. It provides a simple console interface for maintaining basic hospital information.

## ✨ Features

* Add patient details
* Add doctor details
* View patients
* View doctors
* Book appointments
* Cancel appointments
* Search patient records
* Display appointment details

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming
* Java Collections
* JUnit

## ▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
3. Compile the Java source files.
4. Run `Main.java`.
5. Select the required option from the menu.

## 🧪 Testing
